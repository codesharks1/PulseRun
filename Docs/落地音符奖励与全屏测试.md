# 落地音符奖励

退出 Play，等待新脚本导入。点击 `PulseRun → Add Grounded Note Rewards`，然后保存场景。当前 NeonRunway 场景没有未保存修改时，也会自动应用一次。

- 在现有的每个 `StayGrounded` 悬挂障碍下放一个金色双音符。位置与 H 标记同步，不改谱面时间或障碍位置。
- 保持落地碰到音符后，音符消失，播放约 0.24 秒的轻电子铃声和小火花。
- 音符只使用 Trigger，没有实体阻挡，也没有 RunnerHazard，不会造成死亡。
- 同一个音符每次跑图只触发一次。死亡、重试、停止音乐后恢复音符并停止未结束的拾取声。
- 录谱面时仍会和悬挂障碍一起隐藏，避免录制过程中发出拾取声。
- 之后生成谱面会自动添加奖励，不必为奖励重新录制，也不会重复添加。
- 这版只提供视觉和声音反馈，没有增加分数、连击或失败惩罚。

音量可以在障碍子物体 `Grounded Beat Note` 的 `RhythmNotePickup` 组件中调整 `Sound Volume`，默认 0.25。默认声音由脚本合成，不需要下载音效；也可以给 `Pickup Sound` 指定自己的音频。请在退出 Play 后调整并保存。

同一菜单还会隐藏光门上现有的 BOOST、NORMAL 文字及其专用标牌。之后生成的两种光门不再生成这块标牌；门本身与 X/C 加速、恢复速度的逻辑不变。只处理标牌，不重新生成整扇门，因此保留已有光门的其他外观调整。

# 全屏测试

## 编辑器中放大试玩

退出 Play，在 Game 窗口顶部，把 `Play Focused` 改为 `Play Maximized`，再点 Play。Game 将铺满 Unity 编辑器窗口，而不是独占整个显示器。可选 16:9 比例，并关闭 Game 窗口的 Gizmos，避免灯光图标等调试标记遮挡画面。

[Unity 6.3 Game 视图说明](https://docs.unity.com/en-us/engine/6000.3/manual/unity-editor/editor-windows-views-reference/game-view)

## 真正的显示器全屏

使用 Windows 构建版：

1. 保存 `Assets/PulseLook/NeonRunway.unity`，打开 `File → Build Profiles`，选择 Windows 平台或创建并切换到 Windows 构建配置。
2. 在 Scene List 中添加当前场景，把 NeonRunway 设为第一个启用的场景。本项目现有全局构建列表还是 SampleScene，直接构建可能跑错场景。请检查构建配置是否使用独立 Scene List。
3. 在 Player Settings 的 Windows `Resolution and Presentation` 中，将 `Fullscreen Mode` 设为 `Fullscreen Window`（无边框全屏）。
4. `Build And Run`，将输出放到独立的 Builds 文件夹，运行生成的 exe 测试。测试结束可用 Alt+F4 关闭。

[Windows 全屏设置](https://docs.unity.com/en-us/engine/6000.3/manual/platform-specific/windows/playersettings)；[创建构建配置](https://docs.unity.com/en-us/engine/6000.3/manual/building-and-publishing/build-settings/create-build-profile)；[构建基础](https://docs.unity.com/en-us/engine/6000.3/manual/building-and-publishing/building-introduction)。

这次没有自动修改构建配置或打包程序，避免影响现有项目设置。
