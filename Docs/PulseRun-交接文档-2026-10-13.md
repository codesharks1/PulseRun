## 2. 已完成的玩法与反馈

### 移动、死亡、音乐

- Rigidbody负责物理；固定向前速度，保留Y速度；独立重力、较短滞空、跳跃预输入、显示模型翻转和起跳光圈已有。
- 空中停止发射新的摩擦碎块，已有碎块自然消失。额外狂暴喷射是另一套纯视觉粒子，允许在跳跃时存在。
- 碰撞物体或父物体携带 `RunnerHazard` 则死亡；碎裂只触发一次，碎片留在死亡点。停止音乐、暂时禁用玩家、回出生点，再预约重播。
- `RunMusicClock` 用音频 DSP 时间预约播放，`SongTime` 是歌曲时间，不是从进入 Play 起算的 `Time.time`。
- `RunStopped` 停止通知用于立即重置模糊、灯带进度、奖励和狂暴表现，不能只靠渐近归零，否则可能残留效果。

### 谱面与 X/C 加速

- 录制按键：空格起跳、H保持落地、X开启加速、C恢复正常、Backspace撤销、Enter结束。
- X/C只用于录制，游玩时仍主要按空格。速度切换由歌曲时间驱动，门是同一时间/路程上的视觉标记，不是碰撞器驱动。
- `RunChartMotion` 根据段内节拍密度选择速度倍率s，独立重力倍率乘s²，保持目标跳高。普通段仍保留落地安全检查；不是无条件允许任意密度。
- 所有变速后的障碍位置、城市入口都用分段速度积分，不可混用“恒定速度×时间”。
- 当前保存了 `NeonRainbowChart 2/3/4.asset`。Chart 4有19个标记，录到26.73秒；加速区间11.178～17.322秒和20.117～22.271秒。后一个X靠近19.434秒跳跃的空中阶段：正式生成会警告/阻止，可用“生成试玩预览（仅允许空中通过X/C）”按钮原样试玩；其他错误仍拦截。
- 支持从任意歌曲秒数续录：保留前缀和新录制区间之后的原标记，只替换本次覆盖区间，保存为新谱面。这里的“检查点”是录制时间检查点，不是游戏复活检查点。

### 落地音符奖励

- 每个H悬挂障碍下有金色双音符，保持落地触碰后消失、出现小火花并播放约0.24秒bling声。
- 音符是Trigger、无实体阻挡、无RunnerHazard。每轮只拾取一次，停止/重试后恢复；录制时随障碍隐藏。
- 默认声音由脚本合成，不依赖新增音频文件。可在 `Grounded Beat Note → RhythmNotePickup` 调 `Sound Volume` 或指定 `Pickup Sound`。
- 暂无分数、连击或漏音符惩罚，不要把这些当已完成玩法。

## 3. 最新紫电狂暴模式

`Player → Runner Berserk Visuals (Script)` 是参数入口。

- 加速时方块核心、描边、底部灯光、摩擦碎块、跳跃光圈变紫；额外小方块喷射向后增强，进门时火花也朝后甩。
- 电弧沿方块两侧和顶部掠过，尖锐折点、末端收尖、朝后拉长。不是圆环，不做向外扩散的辐射支路。
- 运行时使用6条可复用线：最多4条主电弧和2条短支路，但各自有寿命与空档，不会一直六条都存在。出生时重新选择路径，出现期间独立不规则换形。
- 镜头包含紫色调色、暗角、少量色散、周边紫色光晕和向外移动的速度线；中央障碍尽量保持可读，顶部调试区域不覆盖。没有全屏高频强闪白光。
- C后停止新电弧出生，约0.32秒退回原色；死亡/重试立即清理电弧、额外粒子、滤镜及生命周期。
- 只复制玩家运行时材质来变色，不能直接修改共用的青色材质，否则道路/城市也会变紫。

| Inspector参数 | 当前保存值 | 调节作用 |
|---|---|---|
| Berserk Color | 紫色HDR | 玩家狂暴颜色 |
| Camera Tint | 0.65 | 镜头紫色调色及周边效果总强度 |
| Screen Energy | 0.8 | 镜头边缘光晕和速度线 |
| Trail Multiplier | 2.2 | 摩擦粒子发射量倍率 |
| Lightning Width | 0.03 | 原始基础线宽参数 |
| Lightning Width Multiplier | 2 | 在前一版基础上加粗一倍，优先调这个 |
| Lightning Tail Length | 2.2 | 向后延伸的长度 |
| Lightning Activity | 16 | 出现期间重劈换形活跃度 |
| Lightning Lifetime Seconds | X=0.08，Y=0.20 | 每次出现多久（秒） |
| Lightning Gap Seconds | X=0.04，Y=0.16 | 消失后等多久再出现（秒） |

时间范围中X是最短、Y是最长。寿命越短越像短促放电；空档越大越稀疏。退出Play后调节并保存；Play里改参数只是临时测试，退出通常还原。

## 4. 灯带与23秒城市

- 青色连续安全边线保留。原单侧粉色短灯条已隐藏，新短灯条左右对称、间距4、长度0.9；玩家跑过后粉紫变暖金，重试恢复。
- `Symmetric Reactive LED Strips → RunwayLightTrail` 中的Idle/Passed Color是HDR颜色，可调Intensity。运行时这两个颜色会覆盖材质的对应颜色，不能只调材质然后期待运行时保持亮度。
- 光门有金属底座、动力模块、斜肩、双层发光通道、薄能量幕；BOOST/NORMAL文字与标牌已隐藏，未来生成也不再带字。
- 23秒前是封闭昏暗隧道；出口低亮度光雾常驻，靠近时增强，约23～25秒平滑退白，带轻微残像。
- 城市为悬浮半透明赛道、分层建筑与尖塔、广告牌、高架和下层装饰车流。使用原连续地面碰撞，不会因为透明面板接缝掉落。
- 隧道转场曝光优先级高于狂暴滤镜，但只覆盖曝光，不用默认白色调色冲掉其他色调。镜头边缘覆盖在泛白期间会淡出。
- 转场附近约21.7～25.1秒的障碍按安全区隐藏，原谱面标记保留。进入加速后23秒对应Z会变，生成谱面必要时会重建城市。

## 6. 操作菜单与测试

- `PulseRun → Rhythm Chart Recorder`：录制、续录、保存及生成谱面。
- `PulseRun → Enable Purple Berserk Mode`：绑定狂暴表现组件/材质；已有组件后，仅修改脚本不需每次重新点菜单。
- `PulseRun → Add Grounded Note Rewards`：给已有H障碍补音符、隐藏光门标牌。
- `PulseRun → Setup Symmetric Reactive LEDs`：设置两侧灯带；再次点会把间距设回4。
- `PulseRun → Build Neo City Transition`：构建城市并匹配23秒位置。
- `PulseRun → Capture Neo City Preview`：输出 `PulsePreview/NeoCity-Preview.png`，只是静态城市预览，不包含完整动态转场。

全屏预览：Game顶部 `Play Focused → Play Maximized`，只铺满编辑器。真正显示器全屏需Windows构建，Player Settings中设Fullscreen Window。**当前全局构建列表仍只有SampleScene**，打包前加入NeonRunway并设为首个启用场景；本次没有自动改构建配置。

明天回归测试建议：X后变紫并出现有寿命的随机电弧 → C后恢复蓝色；加速中死亡 → 出生画面不残留紫色/模糊；H下面音符只吃一次、重试恢复；灯带两侧同步变色；城市仍在23秒按正确位置揭示。
