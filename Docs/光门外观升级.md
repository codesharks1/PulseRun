# 加速光门外观 v2

退出 Play 并保存场景，等待新脚本与着色器导入后，使用 `PulseRun/Upgrade Speed Gate Visuals`。只升级现有生成组里的 X BOOST 和 C NORMAL，不修改标记、位置、跑速或重力。

旧灯带模型只隐藏，不删除。升级可撤销，也不会重复叠加 v2 模型。之后重新生成谱面会直接使用新外观。

新外观包含金属底座、动力模块、冷却片、前后两层门框、斜角肩部、入口地面箭头和薄能量幕。紫色是加速门，青色是恢复门。BOOST和NORMAL文字及专用标牌已从当前外观移除，后续生成也不会添加。

`GateEnergy.shader` 使用透明流动扫描线，中间透明度很低，靠近两侧略强。所有装饰几何均没有 Collider，也不挂 RunnerHazard，不会改变通行判定。现有加速仍由歌曲时间驱动，而非装饰模型碰撞。

截图里的灯泡图标属于 Scene 视图的灯光辅助图标，不是门本身的模型，不会出现在 Game 画面。

C# 编译已检查，最终视觉和着色器渲染以 Unity Game 视图试玩为准。备份及交接说明见 `PulseRun-交接文档-2026-10-13.md`。
