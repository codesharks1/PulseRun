# 玩家控制代码阅读路线

当前路线是世界坐标 +Z 方向的直线。玩家没有自动转弯或弯道寻路逻辑。

## 推荐阅读顺序

1. `RunnerController.Awake`：取得 Rigidbody、碰撞盒、显示模型及粒子引用；锁定 X 位置和实体旋转。
2. `RunnerController.Update`：读取空格，记录按键时间；更新显示模型的翻转和起跳光圈。
3. `RunnerController.FixedUpdate`：补充玩家重力 → 音乐未开始时等待 → 检查落地 → 消耗有效的跳跃预输入 → 设置向前速度。
4. `RunnerController.CheckGrounded`：用碰撞盒脚下的小盒子检测 Ground 层。
5. `RunnerRespawn`：碰到 RunnerHazard 后禁用玩家、播放碎片，然后恢复出生位置与音乐。

## 直线移动的核心

```csharp
velocity.x = 0f;
velocity.z = Mathf.Max(0f, forwardSpeed);
body.linearVelocity = velocity;
```

这里不覆盖 `velocity.y`，所以跳跃和重力仍然控制上下运动。

起跳速度按 `sqrt(2 * EffectiveGravity * jumpHeight)` 计算；因此增大重力倍率会缩短滞空时间，而不是直接降低目标跳高。

`jumpRequested` 表示尚未消耗的按键，`jumpPressedAt` 表示按键时刻。落地时仍在预输入窗口内就起跳，起跳后立即清除请求，防止同一次按键重复触发。

## 障碍位置

`RunChartWindow.Generate` 使用「出生位置 + 向前方向 × 行程」。行程由 `RunChartMotion.DistanceAt` 对分段跑速积分计算，地刺还额外加上到达跳跃最高点所需的行程。不能在有 X/C 加速段时退回恒定跑速乘时间，否则谱面和城市入口都会错位。

`StraightRunwaySetup` 只是一次性的场景迁移工具，不参与游戏运行。旧弯道的数学仅保留在迁移工具中；新路面使用单个连续 BoxCollider，远处雾效遮住尽头。这是足够长的有限跑道，不是无限道路生成器。

## 音乐与加速继续阅读

1. `RunMusicClock`：加载音乐、DSP预约播放、SongTime、RunStopped停止通知。
2. `RunChartMotion`：X/C配对、节拍密度适配、分段倍率和路程积分。
3. `RunnerRhythmMotion`：物理更新前应用该段速度及重力，重试时立即清除模糊。
4. `RhythmNotePickup`：落地触发音符奖励，只触发一次并在重试后恢复。
5. `RunnerBerserkVisuals`：表现层；`UpdateArcs`控制电弧寿命、空档、随机换形，`OnGUI`绘制镜头边缘效果，`ResetEffects`负责重置。
