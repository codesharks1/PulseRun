# 紫色光门加速谱面

保持原录制流程：退出 Play、保存场景，在 PulseRun/Rhythm Chart Recorder 开始录制并点一下 Game 窗口。

- 空格：起跳。
- H：保持落地通过悬挂障碍。
- X：开始加速段，生成紫色光门。
- C：结束加速段，生成青色恢复门。
- Backspace：撤销最后一个标记。
- Enter：结束录制。

X/C 是录制指令，正常游玩不需要再按它们。运行时根据歌曲时间切换参数；光门按同一份变速行程放置。每个X必须有对应C，光门要放在落地段，不能在跳跃中切换重力。

## 密度适配

每个 X～C 段统一选用一套速度和重力，不会每拍乱变速。

最低跑速为原速度1.25倍，最高3倍。规划器根据相邻跳跃间隔，以及跳跃到H/C之间的落地时间需求，缩短该段滞空时间。速度倍率为s时，重力倍率乘s²，跳高目标保持不变。因此加速前后单次跳跃的理论水平行程相近。

例如原速度8、跳高1.5、重力倍率2，约0.5秒间隔的跳跃会规划为跑速约14.9、重力倍率约6.94、理论滞空约0.42秒。生成时 Console 会显示每段实际结果。

普通段仍使用原落地间隔检查；加速段使用适配后的落地检查。超过3倍能力、悬挂障碍与跳跃冲突、空中穿门、障碍重叠或缺少C等都会阻止生成，不会默默产生必死关卡。

## 镜头与重置

`RunnerRhythmMotion` 在物理更新前给 `RunnerController` 设置该段跑速和独立重力倍率。加速时使用轻微远景景深模糊，近处玩家和障碍保持清晰。可以关闭其 Background Blur。

重生后按歌曲起始偏移重新计算当前段落。死亡粒子的全局重力不变，原跳跃预输入和起跳光圈保留。

## 23秒城市入口

如果前奏中加入加速，23秒对应的道路位置会改变。障碍和城市入口均使用分段速度积分；生成谱面时，如果入口需要移动，会自动重建城市。重建可能需要等一会儿，结束后请保存场景。

已有谱面不包含X/C时仍然是固定速度，不需要重录。谱面保存为新文件，旧文件不会被覆盖。

## 按原标记强制试玩

录制窗口另有「生成试玩预览（仅允许空中通过X/C）」按钮。它只把空中切换速度/重力的检查降为警告，不改标记时间；密度超限、障碍重叠、缺少C等错误仍然阻止生成。

预览中穿门会立即按该段参数运行，可能改变当前跳跃后半段的轨迹，不保证此种穿门方式的可玩性。满意后可以调整标记再正式生成，不需要删除旧谱面。

实际物理手感和模糊效果以 Unity 内试玩为准。最新交接及备份流程见 `PulseRun-交接文档-2026-10-13.md`。
