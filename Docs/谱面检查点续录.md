# 从检查点继续录制

录制窗口的新区域「从歌曲时间检查点续录」使用歌曲秒数作为检查点，不是新增游戏复活检查点系统。

1. 退出 Play，保存场景。
2. 在「续录原谱面」选择已有 RunChart 文件。
3. 填写「起始歌曲时间（秒）」，或点击「使用原谱面最后录制时间」。
4. 点击「从这个检查点继续录制」，点一下 Game 窗口。
5. 使用空格/H/X/C继续标记，Backspace只撤销这次新标记，Enter结束。
6. 保存为新谱面，再生成并试玩。

例如原谱面0～30秒，从12秒开始、录到18秒：保留12秒之前的标记；替换[12,18)区间；18秒及之后的原标记仍然保留。原文件不修改，保存的是合并后的新文件。

如果12秒之前已经有X、尚未到C，该X会保留，所以可以在加速段中继续标记，不需要再次按X。不要重复开启同一个加速段。

音乐临时从指定秒数开始，冻结的玩家和镜头也会移到原谱面计算出的对应位置。退出录制后不会永久改变场景的音乐偏移或出生位置。

## 加速模糊重置

音乐停止时会立即通知 RunnerRhythmMotion 清除效果；死亡、等待音乐、C结束段和禁用组件时，效果权重直接归零、Volume关闭、DepthOfField模式切回Off。普通段不再使用逐渐趋近0的权重，避免极小非零值仍然启用景深。

在 Unity 内需要验证：加速期间死亡 → 出生后画面清晰 → 再次进入X门才重新模糊；通过C后也应清晰。若复活起始歌曲时间本身位于加速段，音乐开始后重新启用该段效果属于预期行为。
