# 紫电狂暴表现

退出 Play，等待脚本导入，点击 `PulseRun → Enable Purple Berserk Mode`，然后保存场景并试玩。若当前 NeonRunway 场景已保存且没有未保存改动，也会自动应用一次。不需要重录或重新生成谱面。

表现跟随现有 `RunnerRhythmMotion` 的 X/C 分段时间，不另外添加门碰撞触发器，避免视觉和实际加速不同步：

- X 段开始：玩家由原来的蓝色变成紫色，约 0.12 秒进入；向后甩出一束火花，贴着方块两侧和顶部的电弧短促增强，约 0.38 秒回落。
- 加速期间：方块核心、描边、玩家子物体灯光、跳跃光圈和摩擦碎块变紫，摩擦粒子发射量默认 2.2 倍。额外的后向小方块喷射在跳跃时也存在，原摩擦粒子仍然只在落地时发射。
- 镜头：更明显的紫色调色和暗角，叠加紫色边缘光晕、向外移动的周边速度线、少量边缘色散。中央路面只有很轻的覆盖，顶部调试文字不覆盖。保留原有远景模糊，不提高全局 Bloom，不增加视野角度变化，不做全屏白光。
- C 段开始：约 0.32 秒淡回原本颜色，停止额外喷射，恢复原粒子参数。
- 死亡、重试、停止音乐或禁用组件：立即移除电弧、额外喷射和镜头滤镜，恢复玩家原色；不留下紫色滤镜。

在 Player 的 `RunnerBerserkVisuals` 中可调整：

- `Berserk Color`：狂暴颜色（HDR）。
- `Camera Tint`：紫色电影滤镜强度，默认 0.65。觉得紫色太重时降低此值。
- `Trail Multiplier`：摩擦粒子的发射量倍数，默认 2.2。
- `Enable Lightning` / `Enable Jet`：单独关闭电弧或额外喷射。
- `Lightning Radius` / `Lightning Width`：贴身间隙、线宽参数，保留原字段以兼容现有场景。四条主闪电从方块前侧掠过两侧/顶部并朝后拉长，使用尖锐折点和逐渐收尖的线宽，不再画镜头平面的圆环或径向分叉。实际线宽会在旧参数基础上收细。
- `Lightning Tail Length`：电弧朝后延伸的长度，默认 2.2；持续随机出现的两条短支路也朝后甩，不向四周发散。
- `Lightning Activity`：电弧重劈活跃度，默认 16。每条电弧以各自随机的约 45～95ms 间隔明显换形，尾端长短不一、折点跳动，短支路持续随机出现/消失。粗细只做局部小幅变化，不改变屏幕曝光或镜头滤镜亮度。使用独立随机数，不影响其他玩法随机数。
- `Lightning Width Multiplier`：总粗细倍率，默认 2，即在上一版基础上加粗一倍。1恢复上一版粗细，3更粗。
- `Lightning Lifetime Seconds`：每次出现的寿命范围，默认 X=0.08、Y=0.20 秒。X是最短、Y是最长。越短越像短促放电，越长越连续。
- `Lightning Gap Seconds`：消失后到下次出现的等待范围，默认 X=0.04、Y=0.16 秒。越大越稀疏，越小越密集。
- `Screen Energy`：周边紫色光晕与速度线强度，默认 0.8；与 Camera Tint 共同控制，设为 0 可单独关闭镜头能量边缘。

四条主电弧现在各有独立生命周期，不再常驻：出现后不规则跳动，寿命到期立即消失，等待随机空档再劈出新的，出生时重新选择两侧/顶部路径。两条短支路也有寿命。退出加速后不再产生新电弧，死亡/重试立即清空全部生命周期。

这些参数的入口是 Hierarchy 中选中 Player，然后在 Inspector 找 `Runner Berserk Visuals (Script)`。先退出 Play 调整并保存，Play 中改动只用于临时试玩，退出通常会还原。

所有变色使用运行时玩家专属材质副本，不修改道路、城市、其他物体共用的青色材质，不覆盖你在编辑器中调过的原始发光值。电弧和喷射均无 Collider/RunnerHazard，不改变跑速、跳跃、重力、碰撞或谱面。

狂暴滤镜仅覆盖自身需要的调色字段，优先级低于现有隧道转场；转场曝光组件只覆盖曝光，不再用默认白色调色参数覆盖狂暴调色。周边能量覆盖在出隧道的泛白期间同步淡出，出隧道泛白仍由 NeoCitySequence 控制。之后重新生成谱面也会保留/绑定这个表现组件，不重复添加。

此版是概念图方向的第一轮实现，不是直接把概念图贴进游戏。最终亮度、喷射长度、电弧可见度和拾取/障碍的可读性还需 Game 画面实测。
