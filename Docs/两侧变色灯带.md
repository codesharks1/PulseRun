# 两侧变色灯带

退出 Play，等待脚本导入，打开 NeonRunway 场景。点击顶部菜单 `PulseRun → Setup Symmetric Reactive LEDs`，然后保存场景。脚本也会在该场景已经保存、没有未保存改动时自动应用一次。

原青色连续安全边线保留；原单侧粉色短灯条只隐藏，不删除。新短灯条在道路左右内侧对称分布，两边位置、间距相同。

进入 Play 后，玩家实际跑过的位置会让对应短灯条从粉紫平滑变为暖金，已经跑过的灯条保持颜色。按照玩家位置计算，所以加速时也能同步。死亡、重试或停止音乐时重置。

选中 `Symmetric Reactive LED Strips`，在 `RunwayLightTrail` 组件中可以调整：

- `Idle Color`：还没跑过的颜色。
- `Passed Color`：跑过的颜色。
- `Spacing`：短灯条间距，默认 4（较初版密度增加一倍）。再次点击设置菜单也会把已存在灯带的间距更新为 4。
- `Dash Length`：短灯条长度，默认 0.9。

两个颜色字段支持 HDR。点击颜色条，在颜色面板中调 `Intensity`（强度）即可改变发光亮度；先小幅增加，避免泛光过亮。运行时以组件里的颜色和强度为准，会覆盖材质的对应颜色。请在退出 Play 后修改并保存场景，Play 中的临时调整通常不会保留。编辑状态下的材质预览可能与组件设置不同，以 Game 运行效果为准。

这只是环境反馈，不是收集音符，不改变障碍、碰撞或谱面。不需要重新录制或生成谱面；后续重新生成谱面也不会删除这组灯带。

使用两条带间隔裁切的道路网格和属性块更新颜色，不为每个短灯条创建单独物体或材质。着色器跟随当前场景的雾效，避免远处灯条一直透到地平线。
